# CAV Photo Studio, Events, and Coffee Shop
## Static Flutter Application Plan

## 1. Project Overview

The CAV Flutter application is a static mobile application that presents the services offered by CAV Photo Studio, Events, and Coffee Shop.

The application will allow users to:

- View photo studio packages
- View event packages
- Browse coffee shop products
- Select a preferred booking date and time
- Fill out a sample booking form
- View booking and order summaries
- Explore the photo gallery
- View business information and contact details

All information will be stored locally inside the Flutter project. No database, backend, API, or online payment system will be used.

## 2. Main Navigation

Use a bottom navigation bar with the following pages:

- Home
- Studio
- Events
- Coffee
- Profile

The Profile page can be replaced with an About or Contact page because the application does not require user accounts.

## 3. Splash Screen

The splash screen should display:

- CAV logo
- Business name
- Short tagline
- Loading animation

Example tagline:
> Capture Moments, Celebrate Events, Enjoy Coffee

After a few seconds, the user will automatically proceed to the home page.

## 4. Home Page

The home page should include:

- Promotional banner
- Welcome message
